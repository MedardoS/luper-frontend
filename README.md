# LUPER Store

Frontend React + Vite para LUPER.

## Ejecutar
1. npm install
2. Copiar `.env.example` a `.env`
3. Ajustar VITE_ADMIN_PASSWORD y VITE_WHATSAPP_NUMBER
4. npm run dev

## Build
npm run build

## Nota
Los productos de `src/data.js` son datos de demostración. Reemplazar las imágenes por las fotos reales de LUPER.
